# Forbudstid

Turbasert mafiastrategi i 1920-tallets Lakeport, inspirert av Chaos Overlord.
Fire familier kjemper om en by på 8×8 kvartaler: lei bander, ta over kvartaler,
påvirk boliger, butikker og industri, kjøp våpen og knus rivalene.

## Slik spiller du
Åpne `index.html` i en nettleser. Musikken (`musikk.mp3`) må ligge i samme mappe.

## Innhold
- `index.html` – hele spillet (grafikk, regler, datamotstandere, lyd)
- `musikk.mp3` – bakgrunnsmusikk som spilles i loop

Spillet er laget med vibekoding sammen med Claude.
