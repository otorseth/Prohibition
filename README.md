# Forbudstid

Turbasert mafiastrategi i 1920-tallets Lakeport, inspirert av Chaos Overlord.
Fire familier kjemper om en by på 8×8 kvartaler: lei bander, ta over kvartaler,
påvirk boliger, butikker og industri, kjøp våpen og knus rivalene.

## Slik spiller du
Åpne `index.html` i en nettleser. Mappene `css/` og `js/` og filen `musikk.mp3` må ligge ved siden av.

Les **[wikien](wiki/README.md)** for regler, tall og tips.

## Innhold
- `index.html` – siden som binder alt sammen
- `css/style.css` – utseende
- `js/` – spillets kode, delt opp etter tema (regler, kart, kamp, lyd, grensesnitt)
- `musikk.mp3` – bakgrunnsmusikk som spilles i loop
- `tools/lag-artifact.py` – lager versjonen som publiseres som Claude-artifact
- `wiki/` – spillerveiledning og regler
- `CLAUDE.md` – instruksjoner for videre arbeid med AI

Spillet er laget med vibekoding sammen med Claude.
